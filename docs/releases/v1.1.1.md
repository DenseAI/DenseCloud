# DenseCloud v1.1.1

DenseCloud v1.1.1 hardens the public shared-chassis contract without changing
product ownership boundaries.

## Runtime

- Keeps DenseCloud-owned `/health*` and `/metrics` routes reachable when a
  consumer installs root middleware that rejects application traffic.
- Makes the aggregate `/health` endpoint fail closed when liveness, readiness,
  or startup is unavailable.
- Restores the prior process-global OpenTelemetry provider and propagator when
  a DenseCloud OTel provider shuts down.
- Snapshots HTTP metrics before custom collectors run, so collector work does
  not retain the request-metrics lock.
- Uses secure OTLP transport by default and rejects explicit insecure export to
  non-loopback collectors.

## Packaging

- Publishes `dense-base` 1.1.1 with the same version as the root Go module tag.

## Upgrade Notes

- No public Go API is intentionally removed.
- Consumers that previously applied authentication or policy middleware to all
  root routes should move any required probe or metrics controls to
  `SystemMiddleware`, ingress, or NetworkPolicy.
