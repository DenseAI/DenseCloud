# DenseCloud v1.1.0

DenseCloud v1.1.0 promotes the shared HTTP and gRPC chassis, bounded health
checks, ordered shutdown, and executable runtime smoke gates into the public
release line.

## Runtime

- Adds the shared gRPC runtime and canonical HTTP/gRPC middleware presets.
- Preserves RED metrics for requests rejected by consumer middleware.
- Bounds health checks and marks readiness false before transport shutdown.
- Keeps product APIs, authentication, quota, and inference logic outside the
  DenseCloud chassis.

## Packaging

- Publishes `dense-base` 1.1.0 at `oci://ghcr.io/denseai/charts`.
- Includes `LICENSE` and `NOTICE` in the Helm archive and reference image.
- Rejects release tags that do not match the Helm chart version or do not have
  versioned release notes.

## Security

- Updates gRPC, OpenTelemetry, and Redis dependencies to patched versions.
- Adds `govulncheck` to pull-request and release validation.

## Upgrade Notes

- Go 1.25.12 or newer is required so the runtime and standard library include
  the security fixes enforced by the release vulnerability gate.
- Helm consumers must use the lowercase OCI registry path
  `oci://ghcr.io/denseai/charts`.
- No existing DenseCloud public Go API is intentionally removed in this
  release.
